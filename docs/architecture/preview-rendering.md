# Preview Rendering

Preview rendering is browser-local and depends on the active source language.

## Typst

Typst compilation and rendering use the bundled Typst WebAssembly packages. The preview pane manages compile status, diagnostics, successful render state, zoom, paper view, and source jump metadata.

## LaTeX

LaTeX workflows use the browser LaTeX compiler path and BusyTeX package assets. Package resolution is connected to the package cache settings.

## Markdown

Markdown preview stays local to the app and uses the same tab and preview surface model as other supported source types.
