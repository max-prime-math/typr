# Roadmap

Typr's current direction is to keep the app local-first while improving reliability for real writing projects on iPad and desktop.

## Near-Term Focus

- Broaden docs coverage for user workflows and architecture decisions.
- Keep GitHub sync predictable around conflicts, empty repos, and branch setup.
- Improve package cache visibility for offline Typst and LaTeX work.
- Continue tightening mobile and iPad ergonomics.

## Later Candidates

- Trusted local-agent transport for non-browser git workflows.
- Additional import/export formats for project handoff.
- More visual asset workflows for diagrams and graphs.
- More explicit migration and recovery tooling for browser storage changes.
