# Diagrams and Graphs

Typr includes visual tools for diagrams and mathematical graphs so supporting figures can live beside source files in the same browser project.

## Diagrams

The diagram editor supports canvas-based shapes, strokes, assets, and reusable diagram documents. Use it for quick figures that should stay editable in the project rather than being pasted as final images.

## Graphs

The graph editor stores graph snapshots as workspace entries. It supports function rows, styling, axes, labels, and generated graph output that can be inspected and reused in documents.

## Project Storage

Diagram and graph data is part of the Typr project snapshot. Export project backups when you need to move editable visual assets to another browser or device.
